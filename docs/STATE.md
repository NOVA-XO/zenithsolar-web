- **DNS шилжүүлэлт** itools.mn → Cloudflare (компанийн данс, 2FA). Имэйлийн бичлэгүүдийг
  (MX, SPF, DKIM, DMARC, autodiscover, MS/Google TXT) урьдчилан хуулна — үгүй бол компанийн имэйл тасарна.
- Дараа нь: `CNAME`, Pages custom domain, HTTPS, `404.html` base → `/`, LineWorks хөлийн холбоос,
  CSP/хамгаалалтын header (Cloudflare), DMARC-ийг шат дараатай чангатгах.
- Агуулга (эзний мэдээлэл): онцлох 3 төсөл, харилцагчийн үнэлгээ, хүсэлтийн форм.
