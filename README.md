# Zenith Solar — компанийн вэб сайт

Зенит Солар ХХК-ийн танилцуулга сайт: эрчим хүчний зураг төсөл, угсралт, хэмжилт, Zenith LineWorks.

**Сайт:** https://nova-xo.github.io/zenithsolar-web/ (домэйн `zenithsolar.mn` руу шилжүүлэхээр төлөвлөсөн)

## Бүрэлдэхүүн

| Файл | Юу вэ |
|---|---|
| `index.html` | Нүүр: эрчим хүчний зураг төсөл, 6 үйлчилгээ, зургийн галерей, ажлын явц, бидний тухай, тусгай зөвшөөрөл, LineWorks, FAQ, хүсэлтийн ноорог |
| `privacy.html`, `accessibility.html`, `404.html` | Нууцлал, хүртээмж, алдааны хуудас |
| `assets/zs-theme.css`, `assets/zs-theme.js` | LineWorks сайттай **яг ижил** нийтлэг сэдэв (цайвар/бараан горим, толгой, хөл) |
| `assets/site.css`, `assets/site.js` | Энэ сайтын хэв маяг, ангилалтай галерей, зураг томруулах/шилжих, хүсэлтийн ноорог, гар утасны холбоо барих товч, ажлын явц |
| `assets/enquiry.js` | Төслийн хүсэлтийн текст, mailto холбоосыг хөтөч дээр бэлтгэх цэвэр функц |
| `assets/img/` | Лого, бодит төслийн зургууд (webp + jpg) |
| `_archive/old-site/` | Хуучин zenithsolar.mn сайтын хадгалсан хуулбар |

**Хийц:** HTML + CSS + жижиг JS, build алхамгүй, GitHub Pages. Фонт: Google Fonts (Inter, Manrope).
Гар утсанд тохирсон, хөдөлгөөн багасгах тохиргоог хүндэтгэнэ.

## Хүсэлтийн ноорог

Үйлчилгээний картаас сонгоход хүсэлтийн төрөл автоматаар бөглөгдөнө. Байршил, ажлын товчийг
оруулж ноорог бэлтгэнэ. Нэр, эргэн холбогдох мэдээлэл заавал биш.

Сайт хүсэлтийг серверт илгээхгүй, хадгалахгүй, автоматаар имэйл илгээхгүй. Хэрэглэгч нооргоо
шалгаад өөрийн имэйлийн программд нээх эсвэл хуулж илгээнэ. Хэт урт mailto холбоосыг
нээхийн оронд хуулах хувилбарыг харуулна. JavaScript ачаалагдаагүй үед форм нуугдсан,
товч нь идэвхгүй; утас, имэйлээр шууд холбогдох боломжтой.

## Галерей ба хүртээмж

- Эхлээд 6 зураг; бусад зургийг дэлгэх, ангиллаар шүүх боломжтой.
- Томруулсан зурагт өмнөх/дараах товч, зүүн/баруун сум, Tab, Escape ажиллана.
- Цонх нээлттэй үед арын агуулга inert; хаахад анхны зураг руу фокус буцна.
- Зургуудыг ангилсан нь гүйцэтгэсэн төслийн тоог илэрхийлэхгүй. Захиалагчийн нэр,
  гүйцэтгэлийн хугацаа зэрэг баталгаажаагүй мэдээлэл нэмээгүй.

## Шалгах

```text
node --test tools/test-enquiry.mjs tools/test-site.mjs
node --check assets/site.js
```

Build алхам, runtime багцын хамаарал байхгүй. Браузерийн бодит байрлал, цайвар/бараан,
гар утасны хувилбарыг тусад нь шалгана.
